System Architecture

Request Lifecycle

Concrete example: the user changes Time Period from "All" to "March 2025" on the Dashboard. Each step shows where in the stack the work happens.

1
UI
FilterBar emits a change. The dropdown writes to selectedPeriod, a shared ref defined in useFilters.js. Because it's a singleton, every view that imported it sees the new value.
2
View
Dashboard.vue's watcher fires. The watcher on the filter refs calls api.getDashboardSummary(getCurrentFilters()), passing all four filters (warehouse, category, status, month).
3
API Client
api.js builds the request. URLSearchParams are appended for every filter whose value is not 'all', then axios issues GET /api/dashboard/summary?month=2025-03&....
4
FastAPI
Endpoint dispatches. The route in main.py calls apply_filters() on the in-memory inventory_items and orders lists, then filter_by_month() handles both YYYY-MM and Q1-2025 forms.
5
Aggregation
KPIs are computed in Python. Inventory value, low-stock count, pending orders, backlog size, and total order value are calculated from the filtered slices — no database, just list comprehensions.
6
Response
Pydantic validates and serializes. The result is returned via the endpoint's response_model, guaranteeing shape and types before JSON is written to the wire.
7
Reactivity
Vue re-renders. The response updates the summary ref; computed properties (fillRate, categoryData, etc.) recalculate, and the DOM patches the KPI cards and SVG charts.
